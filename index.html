فرض کنید توی برنچ دولوپ هستیم و می خوایم سوییچ کنیم به یه برنچ دیگه. ولی نمی خوایم هنوز تغییراتی که توی برنچ دولوپ دادیم رو کامیت کنیم در این حالت می تونیم کامیت هامون رو توی یک مکان موقت ذخیره کنیم git stash --help git stash -h با نوشتن دستور زیر تغییراتی که در فایلمون ایجاد کردیم در استش قرار می گیرند و ذخیره می شوند git stash دستور زیر هم همون کار دستور قبل رو انجام میده با این تفاوت که اون تغییرات رو با یک پیام در استش ذخیره میکنه git stash save "the massage for example add footer to index.html" با وارد کردن دستور زیر می تونیم لیست استش هامون رو ببینیم git stash list دستور زیر استش موردنظر رو حذف می کنه git stash drop stash@{0} (stash unique code) با وارد کردن دستور زیر می تونیم تغییراتی که انجام دادیم و توی استش ذخیره کردیم رو ببینیم git stash -p show stash@{1} (stash unique code) با دو دستور زیر می تونیم استش موردنظر مون و تغییراتی که توش ذخیره کردیم رو وارد برنچ مون دلخواه مون کنیم فرق این دو دستور اینه که دستور اول بعد از اینکه تغییرات رو وارد برنچ کرد اونارو از استش حذف می کنه ولی دستور دوم فقط تغییرات رو وارد برنچ میکنه و از استش حذف شون نمی کنه git stash pop stash@{1} git stash apply stash@{1} البته بعد از این دستورات باید تغییرات مون رو کامیت و اد کنیم تا تو برنچ اعمال بشن

lesson 8

برای لود کردن پروژه امون روی گیت هاب اول وارد خود گیت هاب میشیم و بعد یک ریپازیتوری برای پروژه مون ایجاد می کنیم و کدی که برای بارگذاری فایلمون به گیت هاب از طریق گیت هست رو کپی می کنیم و در گیت بش پیست کرده و اجراش می کنیم git remote add origin git@github.com:bahar-farshchian/test.git این دستور یک ریموت به پروژه مون ایجاد میکنه و یک اسمی بهش اختصاص میده که به صورت پیش فرض اوریجین هست اگر دستور زیر رو داخل گیت بش وارد کنیم می تونیم لیست ریموت هامون رو ببینیم git remote و برای لود کردن پروژه بعد از وارد کردن دستور قبل دستور زیر رو وارد می کنیم git push -u origin master و به این شکل پروژه مون لود میشه داخل گیت هاب نکته : فایل هایی که ایگنور کردیمشون لود نمیشن داخل ریپازیتوری گیت هاب اگر بعد از لود کردن پروژه مون داخل گیت هاب تغییری در کدهامون ایجاد کردیم و اونهارو کامیت کردیم کافیه تا دستور git push رو بزنیم تا تغییرات داخل ریپازیتوری مون هم اعمال بشن git push -u origin develop به این شکل هم می تونیم یک برنچ دیگه رو لود کنیم داخل ریپازیتوری مون
